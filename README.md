### 🚀 Projets à découvrir

#### [NaturSQL](https://github.com/ChtiAxel/appli_intelligente) — Interroger une base de données en langage naturel

Application web qui transforme des questions en français en requêtes SQL à l’aide d’un modèle exécuté localement avec Ollama. Le projet met l’accent sur la confidentialité et l’exécution encadrée des requêtes.

- Interface réalisée avec Gradio et backend Python.
- Connexion à MariaDB, conteneurisation avec Docker et Docker Compose.
- Exécution SQL en lecture seule avec validation, délai maximal et limite de résultats.
- [Documentation du projet](https://chtiaxel.github.io/appli_intelligente/)

#### [Pokémon TCG SPA](https://github.com/ChtiAxel/pokemon_vue) — Jeu de cartes en ligne

Application Vue 3 pour créer des decks et jouer en ligne. Le frontend communique avec une API REST et Socket.IO pour le matchmaking et les parties en temps réel.

- Comptes joueurs, decks de cartes et lobby de matchmaking.
- Interface TypeScript et Vue 3.
- Backend et base de données démarrables avec Docker Compose.
- [Voir l’application](https://pokemon-vue-two.vercel.app/)

#### [SAE Socket](https://github.com/ChtiAxel/sae_socket) — Programmation réseau

Projet de SAE consacré aux sockets, organisé en versions successives. Le dépôt contient les dossiers `V0` et `V1`.

#### [SAE Graphe IHM](https://github.com/ChtiAxel/SAE_GRAPHE_IHM) — Graphes et interface

Projet Python autour des graphes et d’une interface homme-machine, réalisé dans le cadre d’une SAE.

#### [Application mobile](https://github.com/ChtiAxel/appli_mobile)

Dépôt d’un projet mobile en Dart. Le dépôt public ne fournit pas encore de description détaillée du fonctionnement de l’application.

#### [SAE API Docker](https://github.com/ChtiAxel/SAE_API_docker)

Projet de SAE dont le dépôt contient un projet web/API dockerisé. Consulte le dépôt pour les détails techniques et les consignes d’exécution.
